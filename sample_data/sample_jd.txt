Job Title: Senior Software Engineer — Backend
Company: TechNova Labs
Location: Remote (UK/EU preferred)
Employment Type: Full-time

About the Role
TechNova Labs is looking for a Senior Backend Software Engineer to join our platform team.
You will design and build scalable APIs, contribute to our microservices architecture,
and help shape engineering standards across the team.

Responsibilities
- Design, build, and maintain high-performance REST and GraphQL APIs
- Architect and implement microservices using Python and Go
- Collaborate with frontend engineers and product managers to deliver features
- Write clean, testable code with comprehensive unit and integration tests
- Participate in code reviews and mentor junior engineers
- Monitor and improve system reliability, performance, and observability
- Contribute to infrastructure-as-code using Terraform and AWS

Required Skills
- 5+ years of backend software engineering experience
- Strong proficiency in Python (FastAPI, Django, or Flask)
- Experience with relational databases (PostgreSQL) and query optimization
- Solid understanding of RESTful API design principles
- Experience with containerization (Docker) and orchestration (Kubernetes)
- Familiarity with CI/CD pipelines (GitHub Actions, Jenkins)
- Good understanding of distributed systems and message queues (Kafka, RabbitMQ)
- Strong communication skills and ability to work asynchronously in a remote team

Preferred Skills
- Experience with Go or another statically typed language
- Knowledge of GraphQL and schema design
- Experience with AWS services (Lambda, RDS, S3, SQS)
- Contributions to open-source projects
- Experience working in an Agile/Scrum environment

Experience Required
- 5+ years in a backend engineering role
- 2+ years working with cloud infrastructure (AWS, GCP, or Azure)

Education
- Bachelor's degree in Computer Science, Engineering, or equivalent practical experience

Keywords
Python, FastAPI, Django, Go, PostgreSQL, REST API, GraphQL, Docker, Kubernetes,
AWS, Terraform, Kafka, RabbitMQ, CI/CD, GitHub Actions, microservices, distributed systems,
backend engineering, senior engineer, remote
